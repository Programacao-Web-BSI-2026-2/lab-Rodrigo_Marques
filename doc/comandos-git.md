# Guia Básico de Comandos Git

* **`git clone <url>`** — Baixa uma cópia de um repositório remoto para o seu computador.
* **`git add <arquivo>`** — Adiciona as alterações feitas nos arquivos para a área de preparação (*staging area*). Use `git add .` para adicionar todos os arquivos modificados.
* **`git commit -m "mensagem"`** — Salva definitivamente as alterações preparadas no histórico local com uma descrição do que foi feito.
* **`git push`** — Envia os commits locais para o repositório remoto (como o GitHub).
